**Observations**

- Calculator is not D-Bus-activatable on this system; Text Editor is. Both are found by the fallback.
- The fallback still lists apps whose windows may be closed but whose process lingers (for example Calendar's background service). This is why fallback captures are always partial; the extension removes that ambiguity.
- During setup, `gdbus introspect --dest <name>` briefly auto-started several D-Bus-activatable apps without windows; they exited on their own. Validation scripts should use `busctl --user list`, which does not activate services.

**Not yet validated natively:** the GNOME Shell extension in the user's own session (needs install, log-out and enable; verified only in a headless GNOME Shell).
